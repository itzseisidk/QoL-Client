# [QoL Client]

A lightweight, open-source desktop launcher for Minecraft: Java Edition.

## About

QoL Client is a simple client launcher that lets players sign in with their own Microsoft account and start Minecraft: Java Edition. It is meant as a clean, easy-to-use alternative to the official launcher.

## Features

- Sign in with a Microsoft account (official Microsoft OAuth login)
- Checks that the account owns Minecraft: Java Edition
- Downloads and launches official Minecraft versions
- Manage multiple game versions and profiles
- Adjustable settings (RAM, Java path, game directory)

## Authentication & Privacy

- Login uses the official Microsoft identity platform. Players enter their credentials only on Microsoft's own login page.
- The launcher never sees or stores passwords.
- Access tokens are stored only locally on the player's computer and are used solely to start the game.
- No account data is sent to any third-party server.

## Requirements

- Windows 10/11
- A Microsoft account that owns Minecraft: Java Edition
- Internet connection for login and downloads
